# IMPLEMENT 模式

只能在有效路由和冻结的真实 milestone batch 契约内施工；governance-maintenance target 禁止用于 IMPLEMENT。必须遵守允许/禁止目录、机器契约、测试和停止条件。不得修改路线、契约、顶层设计、公共契约或生成文件。
