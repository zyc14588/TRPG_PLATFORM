# 官方原创隐藏信息竞争桌游规范

<a id="SPEC-BOARDGAME-POSITIONING"></a>
## 1. 定位

与官方 TRPG 共享原创世界观或品牌意象，但存档、规则和剧情状态独立。正式认证 3—4 人，单局 30—60 分钟。

<a id="SPEC-BOARDGAME-LOOP"></a>
## 2. 核心循环

私人手牌/资源与少量私人目标 → 同时秘密规划 → 锁定 → 按公开优先级与速度确定性解析 → 地点竞争、卡牌、骰子和攻击 → 淘汰/复归 → 批次结束检查秘密胜利 → 公开终局与计分。

<a id="SPEC-BOARDGAME-ASymmetry"></a>
## 3. 非对称与行动点

角色或派系具有有限非对称能力和初始条件，但共享同一状态机和行动经济。每轮有限行动点分配给地点、手牌、能力和干扰。

<a id="SPEC-BOARDGAME-VICTORY"></a>
## 4. 双胜利路径

正常路径为固定轮数或公共终局后的确定性计分。少量终局型秘密目标在整个规划批次解析完成后统一检查；多人同时满足时比较目标优先级、公开分数和固定平局规则。

<a id="SPEC-BOARDGAME-RANDOM"></a>
## 5. 随机

服务器权威洗牌、抽取、随机事件和骰子。真人与标准 AI 遵守相同随机、行动点和资源规则。玩家可通过信息、资源、能力和选择降低风险。

<a id="SPEC-BOARDGAME-CONFLICT"></a>
## 6. 高烈度竞争

正式模式从第一轮允许资源摧毁、行动压制和提前淘汰，不设统一最低资源/行动保障。快速和教程模式不淘汰，并保证后续至少一个有意义的行动路径。

<a id="SPEC-BOARDGAME-ELIMINATION"></a>
## 7. 淘汰与复归

被淘汰者只看公共状态和日志，不能聊天影响对局、读取新秘密或控制 AI。只有包定义的卡牌、地点或能力可复归，房主不能撤销。

<a id="SPEC-BOARDGAME-AI"></a>
## 8. AI

标准 AI：合法动作生成 + 启发式/有限搜索 + LLM 高层意图，只有席位正常视图。

高难度 AI：房主开局前启用并锁定，可按游戏包逐字段清单读取额外私人信息。玩家侧仅显示“高难度”。浏览器本地模型不得承担；服务器模型、服务器侧 BYOK 和自托管服务器网关可以。公开解释不得泄露利用的秘密。

<a id="SPEC-BOARDGAME-TUTORIAL"></a>
## 9. 教程与快速模式

使用相同回合、行动、私密信息和计分内核，仅减少区域、卡牌、目标和轮数，并转换淘汰为非淘汰后果。
