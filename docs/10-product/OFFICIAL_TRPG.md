# 官方原创规则异常 TRPG 规范

<a id="SPEC-TRPG-POSITIONING"></a>
## 1. 定位

官方 TRPG 是调查、恐怖、生存、奇幻异常与区域战斗结合的高复杂度模拟游戏。单次模组与 3—5 Session 短战役使用同一原创世界和正式规则。

<a id="SPEC-TRPG-WORLD"></a>
## 2. 世界结构

稳定据点连接多个案件和异常地点。短战役包含至少两个派系、持续威胁、可变化 NPC、贯穿谜团和多条最终路径，不使用唯一章节顺序。

<a id="SPEC-TRPG-RULE-LAYERS"></a>
## 3. 规则异常三层模型

1. **客观异常法则**：主持侧锁定真相；
2. **世界内规则声明**：公告、手册、录音、口述等，可真实、部分真实、过时、错误或伪造；
3. **角色规则知识**：每个角色的见闻、推测、验证、反证和分享状态。

世界内文本永远是游戏数据，不能提升为平台或模型系统指令。

<a id="SPEC-TRPG-SUBSYSTEMS"></a>
## 4. 六类子系统

调查证据、异常规则遵守、压力认知、生存资源、社会互动、区域制战斗，共享类型化状态/命令/事件内核。

<a id="SPEC-TRPG-RESOLUTION"></a>
## 5. 核心判定

百分骰下掷；核心素质、训练技能、专业特长三层能力；难度、优势/劣势和有限修正；结果为卓越成功、成功、带代价成功、失败推进、预警条件下的灾难性失败。

<a id="SPEC-TRPG-INVESTIGATION"></a>
## 6. 调查与证据

核心线索由合理行动获得，检定影响信息质量、代价、时间、暴露和额外收益。证据记录来源、载体、完整性、可靠性、可见性、解释和保管链。禁止一次失败永久卡死主线。

<a id="SPEC-TRPG-EXPERIMENT"></a>
## 7. 规则试验

正式结构化试验只由随机天赋池中的特定天赋解锁，允许全队无人获得且完全没有正式试验方法。官方内容必须提供替代调查路径。试验由天赋角色单独执行，可预先获得物品，但其他角色不提供试验协作加成；珍稀资源可换额外信息或重试。

<a id="SPEC-TRPG-ANOMALY"></a>
## 8. 异常风险与补救

违规流程为匹配法则 → 暴露 → 检测 → 严重度 → 反应窗口 → 补救/代价 → 后果。风险至少包括区域失稳、实体注意和个人标记/污染。极稀缺具体资源可在规则窗口内缓解或逆转致命结果，但必须留下原事件、消耗和残留后果。

<a id="SPEC-TRPG-SOCIAL"></a>
## 9. 社会互动

技能检定、自然语言内容、目标、立场、证据、关系、筹码、承诺和代价共同解析。普通社会成功不能无条件控制 NPC 或真人。预定义精神控制特殊能力判定成功时，可在明确动作范围和时限内控制真人角色，但不能控制账户、安全暂停或现实行为。

<a id="SPEC-TRPG-COMBAT"></a>
## 10. 区域战斗

明确轮次、主要行动、机动/准备和有限反应。区域图记录连接、视线、掩体、高低差、危险和撤离。攻击结合成功等级、武器、距离、护具和具体伤势。PVE 无通用投降，但可完成目标、撤退、掩护救治或按敌方规则脱离。

<a id="SPEC-TRPG-DEATH"></a>
## 11. 死亡与替代角色

致命结果先进入逆转窗口；活着角色可消耗适用资源逆转。终局死亡后，原玩家在当前活动阶段仅看公共内容，不影响游戏；下一安全边界引入追赶配置替代角色，不能继承元知识或全部秘密。

<a id="SPEC-TRPG-AI-HOST"></a>
## 12. AI 主持

维护 Campaign、Session、场景、NPC 分层计划；计划不是事实。核心真相不得动态修改。公开裁定展示规则、公开输入和结果，不展示秘密、未触发计划或隐藏推理。
