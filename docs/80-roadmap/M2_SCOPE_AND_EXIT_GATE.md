# M2 范围与出口门禁

本里程碑落实既有 `SPEC-V1-ROADMAP-M2` 和当前 M2 REQUIRED 需求，不扩大 V1。平台侧批次 ID 由本仓库原生计划分配；Rules 仓库的 M2-B001 历史资格继续按其自身来源保留。

<a id="SPEC-M2-ALLOWED"></a>
## 1. 允许范围

- 账户、工作区和显式关系权限；受邀访客仅单局参与及后续认领，不能拥有长期资产、上传包、保存长期凭据或获得管理权限。
- 私人房间、可过期邀请链接和代码、可选审批；所有者、管理员、主持人与席位控制者分开授权，邀请只授予加入资格。
- 游戏和内容选择、包清单同意、兼容性、席位、模型、内容边界、必要准备的启动硬门禁。
- 将已验收 SessionActor、事件/快照/Outbox、幂等命令、权限过滤和重连基础接入正式平台应用服务。房间大厅、账户和工作区使用事务服务，不进入 SessionActor。
- 持久任务、Continuation 和 workerd 回调，以新的系统命令回到 Actor；不在权威事务中等待外部任务。
- 服务器侧模型网关、OpenAI-compatible/Ollama/llama.cpp 兼容服务器、模型能力和认证绑定、BYOK 加密或会话临时凭据。
- AI 席位各自的视图、身份、记忆、工具和多级预算；动作先验证提交再叙事，有限重试及预授权兼容后备，硬上限暂停。
- 玩家界面接入私人房间、席位、准备、同步游戏、恢复点和权限过滤导出；高级模型配置按现有体验规范呈现。
- Linux amd64 单节点 Compose：反向代理、唯一权威 platformd、workerd、lua-runner、PostgreSQL 和对象存储；内部管理服务不暴露公网，秘密通过只读文件提供。
- 本里程碑的版本化公共协议草案及契约测试。新增或改变公共契约、Host API 或许可时须按 CHANGE 门禁先获批准；草案不能直接授权实施。

<a id="SPEC-M2-FORBIDDEN"></a>
## 2. 禁止范围

- 公共房间浏览、陌生人匹配、市场、交易、评分和社区发布。
- 浏览器本地模型、水平复制、多权威 platformd 或对中央账户/许可证控制面的自托管依赖。
- 无席位管理员旁观私密内容、访客获得长期资产或管理权、提示词层面的虚假信息隔离。
- 权威事务同步等待模型、无限重试、未授权后备、静默超支或静默 AI 接管。
- 提前实现 M3/M4 官方完整垂直切片、M5 Campaign、M6 Studio 完整产品或 M7/M8 托管发布；现有最小测试包可作为 M2 测试载体。
- 修改已完成 M1 冻结契约、后端固定身份、许可或既有验收结果；绕过签名、有效路由、公共契约变更批准及必需检查。

<a id="SPEC-M2-EXIT"></a>
## 3. 出口门禁

1. 13 个 M2 REQUIRED 需求各有与准确候选绑定的可重复命令、实际退出码和机器报告，最终全部通过；全里程碑通过必须由完整业务证据支撑。
2. 私人房间的账户/访客加入、包同意、分离角色、真人/AI 席位、准备门禁和 Session 启动形成端到端闭环；缺任一门禁时启动拒绝并保持状态。
3. 不同工作区的相同对象哈希、关系数据、安装与导出保持权限独立；越权、访客长期资产、无席位私密读取等负向测试通过。
4. 客户端、AI、Lua 和 UI 只能提交命令；事件与 Outbox 先原子提交，Actor 串行运行，断线重连恢复游标、视图和待处理行动且不重复命令。
5. AI/外部任务通过持久 Continuation 回到 Actor；跨崩溃、超时、重复回调和状态版本变化的测试通过，无事务同步网络等待。
6. AI 的身份、视图、记忆和工具在构建上下文前隔离；认证绑定模型、端点、适配器、模板、工具及测试版本，失败后备和多级硬预算符合现有规范。
7. BYOK、Cookie、会话令牌、服务端密钥不进入提示、普通日志、包或导出；权限过滤导出及恢复点通过实际验证。
8. Linux 同主机分进程 Compose 实际完成启动、健康检查、平台闭环、持久化恢复、服务隔离和任务资源清理；配置检查不能替代生命周期验证。
9. 所有正式批次完成规定验收、原生状态接收和证据封存；公共契约批准及所有必需仓库检查通过，未解决必需发现为空。

## 4. 需求与测试

本门禁引用原需求和测试，不重写其资格：REQ-PRODUCT-001、REQ-PLAYER-001/002/003/004/005/007、REQ-SESSION-001、REQ-LUA-005、REQ-AI-001/003、REQ-DATA-002、REQ-OPS-001；对应 TEST ID 以 TRACEABILITY.yaml 为准。基础批次可以提供其中一部分证据，最终端到端批次汇总完整要求；只完成基础库不能宣告 M2 出口满足。
