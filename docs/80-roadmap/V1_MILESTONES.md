# V1 里程碑与实施顺序

<a id="SPEC-V1-ROADMAP-M0"></a>
## M0：仓库冻结与重启基线

签名冻结旧项目、活动树零迁移、PolyForm 新许可边界、权威文档/决策/追踪、Monorepo 空骨架、projectctl/Just、跨平台 CI 和渐进式 Codex。不得实现业务。

<a id="SPEC-V1-ROADMAP-M1"></a>
## M1：包规范与最小一致性游戏

冻结包身份/清单/依赖/Host API 的首个可执行版本，选定 Lua 5.5 VM，实现最小 Session/事件/包加载/恢复夹具，并长期作为兼容、迁移和部署烟雾测试。

<a id="SPEC-V1-ROADMAP-M2"></a>
## M2：平台核心与服务器侧 AI

账户、工作区、房间、席位、SessionActor、事件/快照/Outbox、实时同步、模型网关、BYOK、能力探测、AI 隔离和 Linux Compose。

<a id="SPEC-V1-ROADMAP-M3"></a>
## M3：官方隐藏信息桌游

3—4 人、教程/快速/正式模式、秘密规划、混合随机、淘汰/复归、标准 AI、高难度服务器侧 AI、恢复和重放。完成后只进入封闭技术预览。

<a id="SPEC-V1-ROADMAP-M4"></a>
## M4：官方 TRPG 单次模组

AI/真人主持、1—4 玩家、自然语言行动、规则异常、调查、压力、伤势、生存、社会、区域战斗和 2—4 小时完整模组。

<a id="SPEC-V1-ROADMAP-M5"></a>
## M5：Campaign 与短战役

跨 Session 状态、长期记忆/压缩、NPC/派系/威胁、成长、主持交接、成员变更、死亡替代、包迁移和完整导出。

<a id="SPEC-V1-ROADMAP-M6"></a>
## M6：Creator Studio 基础版

离线项目、六类模板、无代码主流程、混合编辑、未知字段、冲突、预览、测试 DSL、素材、AI 差异助手、构建验证和 CLI 等价。

<a id="SPEC-V1-ROADMAP-M7"></a>
## M7：私人内容、托管 Beta 与部署硬化

私人上传/房间传输、签名/认证、托管多租户 Beta、自托管本地模型网关、离线局域网、备份恢复、迁移、性能和 Alpha→Beta 契约冻结。

<a id="SPEC-V1-ROADMAP-M8"></a>
## M8：公开 V1

最小游戏持续通过；两个官方游戏和 TRPG 短战役完成；AI 认证、Studio、CLI/SDK、托管/自托管、离线、导出备份、迁移、安全、许可和发布门禁全部通过。
