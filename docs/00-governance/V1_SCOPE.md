# V1 产品范围、非目标与范围冻结

<a id="SPEC-V1-SCOPE-DEFINITION"></a>
## 1. V1 定义

V1 是一个由游戏包和模组驱动的 AI 原生在线桌面游戏平台。用户可以选择游戏和内容，独自与 AI 完成整场游戏，也可以邀请真人；空缺席位由符合游戏包声明的 AI 补足。平台同时支持有主持人的 TRPG 和无固定主持人的桌游。

<a id="SPEC-V1-SCOPE-MUST"></a>
## 2. V1 必须交付

### 2.1 玩家平台

- 桌面 Chromium Web Player；
- 账户与单次访客；
- 工作区隔离；
- 私人房间、链接和房间代码；
- 真人/AI 混合席位；
- 文本频道、暂停、重连、恢复与导出；
- 内容标签、安全暂停和退出；
- 官方托管与 Linux Docker Compose 自托管；
- 纯局域网自托管能力。

### 2.2 游戏包与创作

- 游戏系统、内容、素材、UI 扩展和 library 包；
- Bundle、精确依赖锁、签名、验证与认证状态；
- Creator CLI、SDK、测试 DSL；
- 私人本地导入与工作区上传；
- Windows/Linux Creator Studio 基础版；
- 离线无代码与混合创作；
- 可重复构建、素材管线和简体中文本地化基础。

### 2.3 官方隐藏信息桌游

- 正式认证 3—4 人；
- 同时秘密规划、确定性解析；
- 私人手牌/资源/目标、公共区域与公开计分；
- 卡牌和骰子混合随机；
- 公开计分与秘密立即胜利；
- 正式模式高烈度竞争、淘汰与规则化复归；
- 快速/教程模式无淘汰和最低有效参与保障；
- 标准公平 AI 与服务器侧高难度信息优势 AI。

### 2.4 官方原创 TRPG

- 原创规则异常调查世界；
- 一个 2—4 小时单次模组；
- 一个 3—5 Session 短战役；
- AI 主持、真人主持、真人/AI 混合玩家；
- 调查证据、异常规则、压力认知、生存、社会、区域战斗；
- 自然语言行动转结构化命令；
- Campaign 记忆、压缩、主持交接、角色死亡与替代；
- 完整存档、恢复和日志。

### 2.5 AI 与模型

- 服务器侧模型网关；
- 平台模型与服务器侧 BYOK；
- OpenAI-compatible、Ollama、llama.cpp 兼容服务器；
- 自托管本机/局域网模型；
- 席位级模型、能力探测、认证、预算和失败恢复；
- AI 动作与叙事分离；
- 权限过滤的记忆和交接包。

<a id="SPEC-V1-SCOPE-NONGOALS"></a>
## 3. V1 明确非目标

- 浏览器直接调用本机模型；
- 手机和平板正式支持；
- 原生移动应用；
- 实时语音、ASR、TTS；
- 公共房间、陌生人匹配、公开招募；
- 公共内容市场、评分、交易和收益分成；
- Creator Studio 正式多人游玩；
- 普通观察者；
- Studio 实时多人共同编辑；
- Kubernetes、分布式服务器、Active-Active、自动主备和零停机；
- 任意原生插件、C Module、游戏包任意网络/文件访问；
- 所有桌游类型通用适配；
- 公共竞技排名与严格可信的浏览器本地计算。

<a id="SPEC-V1-SCOPE-PRIORITY"></a>
## 4. 冲突优先级

用户体验 > 跨规则和桌游扩展 > AI 主持质量 > 内容管理 > 模型兼容。

<a id="SPEC-V1-SCOPE-CHANGE"></a>
## 5. 范围冻结

R0—R24 构成冻结 V1 基线。新增功能默认进入 V1.x 或 V2。只有以下情况可进入 V1：

1. 修复安全、权限、数据丢失或许可阻塞；
2. 满足已有 V1 验收要求；
3. 修复两个官方游戏无法完成的问题；
4. 明确移除或推迟同等及以上工作量的现有 V1 内容。

“未来可能需要”“其他平台有”“顺便实现”不构成变更理由。
