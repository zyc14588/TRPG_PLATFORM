# AI 席位、主持、模型路由与长期记忆

<a id="SPEC-AI-SEAT"></a>
## 1. 席位隔离

每个 AI 席位有独立身份、角色、视图、私有记忆、工具、模型配置和预算。隐藏信息在上下文构建前过滤，禁止把全量状态发送给模型后仅靠提示词“假装不知道”。

<a id="SPEC-AI-HOST"></a>
## 2. AI 主持

对外只有一个权威主持席。内部规则顾问、记忆检索、NPC 规划、叙事生成等子 Agent 只返回建议，不能提交权威事件。主持维护 Campaign、Session、场景和 NPC 分层计划，计划不是事实。

<a id="SPEC-AI-ACTION"></a>
## 3. 动作与叙事

AI 先输出结构化动作提议，经权限、规则、资源和状态版本验证并提交事件后，再生成最终叙事。叙事失败不回滚合法事件，使用确定性模板显示结果。

<a id="SPEC-AI-MEMORY"></a>
## 4. 记忆

分层为权威结构化状态、当前工作上下文、事件摘要、Campaign 长期记忆、席位私有记忆。压缩结果记录来源事件、事实等级、可见性和生成器版本；推测不能升级为世界事实。

<a id="SPEC-AI-MODEL"></a>
## 5. 模型与认证

模型按 MC-0 至 MC-4 或等价等级认证：不可用、叙事辅助、结构化工具、AI 玩家、AI 主持；再叠加游戏专属测试。认证绑定模型、端点、适配器、提示模板、工具模式和测试版本。

<a id="SPEC-AI-BYOK"></a>
## 6. BYOK

普通模式平台按能力路由。高级模式允许用户选兼容模型、端点、预算和后备。密钥使用加密凭据库或会话临时存储，不进入提示词、包、普通日志和导出。

<a id="SPEC-AI-FAILURE"></a>
## 7. 失败和后备

有限重试与格式修复；只有用户预授权且通过能力要求的后备模型可接管。无后备时暂停 AI 席位并保留权威状态，禁止无限重试、静默升价或跳过回合伪装成功。

<a id="SPEC-AI-BUDGET"></a>
## 8. 预算

工作区、房间、Session、席位和任务多级预算覆盖调用数、Token、费用、延迟、工具、子 Agent、上下文和本地计算。硬上限暂停，不得静默超支。

<a id="SPEC-AI-LOCAL"></a>
## 9. V1 本地模型

V1 仅支持服务器侧 OpenAI-compatible、Ollama 和 llama.cpp 兼容服务器，以及自托管本机/局域网网关。浏览器本地模型为 Post-V1。
